# Top-K mask 自适应算术编码统计

本结果只统计两个尺度的第二层激活 mask，不包含第一层索引、第二层激活索引、LDPC、BPSK 或信道指标。

## 设置

- 数据集：24 张 Kodak-256。
- 选择：每张图片、每个尺度独立 Top-K；`1` 表示第二层激活，`0` 表示 STOP。
- 尺度 0：1024 token，原始显式 mask 为 1024 bit/图。
- 尺度 1：256 token，原始显式 mask 为 256 bit/图。
- 原始 mask 合计：1280 bit/图。
- 编码器：32-bit 整数二元算术编码器。
- 概率模型：每个图片/尺度独立，初始 Laplace 频数为 `(zero=1, one=1)`，每编码一个符号后同步更新；不需要发送概率表。
- 外层 framing：token 数和算术段 payload 长度假定已知，不计入 payload bit。
- 验证：全部 528 个 mask 段均完成实际编码和解码，并逐 bit 等于原 mask。

## 结论

算术编码根据0/1概率压缩，不要求相同值在空间上连续，因此10%和90%的零散 Top-K mask 仍可节省约52.16%。50%时0/1概率接近相同，原始 mask 已接近不可压缩；自适应概率学习与算术终止带来平均10.375 bit/图的额外开销，因此比1280 bit原始 mask高0.811%。

数学核对使用该自适应 Laplace 模型对长度为 `N`、包含 `A` 个1的任意序列赋予的信息长度：

```text
log2(N + 1) + log2(C(N, A))
```

22组逐尺度实际码长全部不低于该信息长度，并且算术终止/整数舍入开销最大不足2 bit，符合实现预期。
