# RAQ-RVQ 四组配置：AWGN、5/8 LDPC、QPSK

使用指定原脚本及其默认 mixture-per-K 检查点。每项 SNR 采用 42–51 共 10 个种子，每种子评估 Kodak 24 张图。

码本顺序为 scale 0 的两个 RVQ 阶段、scale 1 的两个 RVQ 阶段；combined 打包。

PSNR 对逐图 dB 值及种子求平均。MS-SSIM 先对原始值及种子求平均，再按 -10*log10(1-mean) 转成 dB。

实际传输比为复数信道符号数 / RGB 元素数。

原启动脚本在评估期间仅有默认码本及默认 SNR 的外部更新；本次采用显式环境参数，四份结果中的实际配置已逐项核对，未受默认值变化影响。
